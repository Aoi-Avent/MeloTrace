# MeloTrace (メロトレース)

> **眠っていたYouTubeの視聴履歴が、あなた専用の最高の音楽アプリになる。**  
> スマホに特化したYouTube音楽履歴アナライザー＆ミュージックプレイヤー

---

## 概要

**MeloTrace** は、YouTubeの視聴履歴から音楽動画（MV、歌ってみた、ボカロ、作業用BGM、シティポップ等）だけを自動抽出し、自分専用の音楽ラウンジを構築するWebアプリケーションです。

PCを持たないユーザーでも、スマートフォンのブラウザでURLを開くだけですぐに使えます。

## 主な特徴

- **スマホ特化のUI/UX**: 片手で操作できるボトムナビゲーション、ミニプレイヤー、フルスクリーン再生シート。
- **ワンタップ体験モード**: 履歴データが手元にない場合でも、1タップで約120曲の厳選サンプル履歴を即座に読み込み可能。
- **とりあえずシャッフル再生**: ホーム画面の巨大ボタンを押すだけで、過去のお気に入り曲をノンストップで再生。
- **気分で選ぶクイックミックス**: 「いつもの定番」「作業・深夜のチル」「テンションMAX」「懐かしのあの曲」「隠れた名曲を発掘」。
- **音楽カルテ・分析**: 音楽DNA、ジャンル比率、最多リピートTOP10、最愛アーティストランキング、昔よく聴いていた「ご無沙汰の名曲」サジェスト。
- **高機能プレイヤー**:
  - LRC形式のタイムスタンプ同期歌詞（リアルタイム自動スクロール＆ハイライト）
  - YouTube公式プレイヤーでの映像再生タブ
  - 次の曲キュー管理
  - スリープタイマー（15分〜60分）、再生速度変更（0.75x〜1.5x）、シャッフル/リピート
  - スマホの画面ロック・通知バーから操作できる Media Session API 対応
- **プライバシー保護**: すべてのデータは端末内（ブラウザのローカルストレージ）に保存され、外部サーバーへ個人情報が送信されることはありません。
- **絵文字ゼロの洗練されたベクターアイコンデザイン**: Lucide Icons によるクリーンで統一感のあるデザイン。

## 技術スタック

- **フロントエンド**: React 19, TypeScript
- **スタイリング**: Tailwind CSS v4
- **ビルドツール**: Vite
- **アイコン**: Lucide React
- **アニメーション**: Motion

## 開発環境のセットアップ

```bash
# リポジトリのクローン
git clone https://github.com/あなたのユーザー名/melotrace.git
cd melotrace

# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (http://localhost:3000)
npm run dev

# プロダクションビルド
npm run build
```

## GitHub Pages への公開方法

1. **ZIPからGitHubリポジトリを作成する場合**
   - ZIPを解凍し、中身のファイルをGitHubリポジトリにアップロードします。
   - ⚠️ **重要**: ブラウザのセキュリティ仕様上、フォルダ丸ごとドラッグ＆ドロップすると「`.github`」隠しフォルダが除外されます。
   - そのため、GitHub上で **「Add file」→「Create new file」** をクリックし、ファイル名に `.github/workflows/deploy.yml` と入力して、`github-actions/deploy.yml` の内容を貼り付けて保存（Commit）してください。

2. **GitHub Pagesの設定**
   - リポジトリの **「Settings」タブ →「Pages」** を開きます。
   - **「Build and deployment」>「Source」** を「**GitHub Actions**」に変更します。
   - これで数分後に自動的にGitHub Actionsがビルドを実行し、公開URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）が発行されます。
