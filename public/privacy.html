プライバシーポリシー

制定日・最終更新日：2026年10月26日

MeloTrace（メロトレース。以下「本アプリ」）の運営者（GitHub：aoi-avent。以下「運営者」）は、本アプリにおける利用者の情報の取り扱いについて、以下のとおり定めます。

1. 基本方針

本アプリは、利用者のブラウザ上だけで動作するWebアプリです。運営者は利用者のデータを保存するサーバーを持っておらず、視聴履歴や再生データを運営者が受け取ることはありません。

2. 端末内（ブラウザ内）に保存される情報

次の情報は、利用者の端末のブラウザ（IndexedDB・localStorage）にのみ保存され、運営者には送信されません。

  • 利用者が取り込んだYouTube視聴履歴ファイル（JSON・MHTML等）から抽出した、曲名・アーティスト（チャンネル）名・動画ID・再生回数・最終再生日時などの情報
  • スキ（お気に入り）、非表示（Ban）設定、プレイリスト、歌詞の表示設定・調整値、並び替え設定などのアプリ設定
  • 取得した歌詞のキャッシュ

取り込みファイルの解析は、すべて利用者のブラウザ内で行われ、外部にアップロードされません。ブラウザのデータを消去すると、これらの情報も削除されます。

3. Googleアカウントでのログインとクラウド保存（任意）

ログインは任意です。ログインしなくても、本アプリの基本機能はすべて利用できます。ログインした場合、次のとおり取り扱います。

3-1. 取得するGoogleアカウント情報

  • メールアドレス、表示名、プロフィール画像（アカウントの表示のためだけに使用し、利用者の端末内に保存します。運営者には送信されません）

3-2. Googleドライブへの保存

  • 利用するアクセス権限：drive.appdata（本アプリ専用の非表示データ領域）。利用者のドライブ内の他のファイルには、アクセスできません。
  • 保存する内容：スキした曲の動画ID、非表示にした曲・アーティスト、プレイリスト、アプリ設定を記録した設定ファイル（melotrace-sync.json）1つのみ。
  • 保存しないもの：視聴履歴の全件、再生回数、動画・音声そのもの。
  • このデータは利用者自身のGoogleドライブに保存されるものであり、運営者がアクセス・閲覧・収集することはできません。

3-3. アクセストークンの扱い

Googleから発行されるアクセストークンは、ブラウザのメモリ上にのみ保持し、端末に保存しません（有効期限は約1時間です）。

3-4. Google APIサービスのユーザーデータに関するポリシー

本アプリによるGoogle APIから受け取った情報の使用および他アプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に準拠します。取得した情報は、本アプリの機能（設定の保存と呼び出し、アカウント表示）の提供以外には使用せず、第三者への提供、広告への利用、販売は行いません。

4. 外部サービスとの通信

本アプリは、機能の提供のために次の外部サービスと通信します。通信時に、利用者のIPアドレス等の情報が各サービス提供者に送信される場合があります。

  • YouTube（Google）：動画の再生（埋め込みプレーヤー）、サムネイル画像の表示、字幕情報の取得。再生時に広告が表示される場合があります。
  • LRCLIB（lrclib.net）：歌詞の検索。曲名とアーティスト名を送信します。
  • Google Identity Services / Google ドライブAPI：ログインとクラウド保存（ログイン時のみ）。
  • GitHub Pages：本アプリの配信。

「YouTubeの視聴履歴にも残す」設定をオンにした場合、動画プレーヤーをyoutube.comのドメインで読み込みます。この場合のCookieや視聴履歴の扱いは、GoogleおよびYouTubeのプライバシーポリシー・利用規約に従います。

各サービスにおける情報の取り扱いは、それぞれの提供者のプライバシーポリシーをご確認ください。

5. 情報の削除・アクセス権限の取り消し

  • 端末内のデータ：アプリ内の「取込・設定」にある「全データをリセット（初期化）」、またはブラウザのサイトデータ削除で消去できます。
  • ログインの解除：アプリ内の「ログアウト」で、アクセス権限を取り消します。
  • Googleアカウント側での取り消し：Googleアカウントの権限管理で本アプリのアクセスを削除できます。
  • クラウド上の保存データ：Googleドライブの「設定」→「アプリの管理」から、本アプリの非表示データを削除できます。

6. 利用者のデータの第三者提供

運営者は、そもそも利用者のデータを受け取らないため、第三者に提供することはありません。

7. 子どものプライバシー

本アプリは、13歳未満の方を対象としていません。

8. 本ポリシーの変更

本ポリシーを変更する場合は、本ページに掲載して通知します。変更後も本アプリを利用された場合は、変更後のポリシーに同意したものとみなします。
